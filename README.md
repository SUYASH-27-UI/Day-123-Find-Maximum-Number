# Python Day 123 - Find Maximum Number

This Python program finds the largest number in a list using the built-in `max()` function.

## Example

Input list:
```text
[10, 45, 20, 80, 35]
```

Output:
```text
Maximum number: 80
```

## Concepts Used

- Python lists
- `max()` function
- Variables
- `print()` function

## How It Works

The program stores numbers in a list. The `max()` function finds the largest value, which is stored in the `maximum` variable and displayed on the screen.
